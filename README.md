# ITC – Simulateurs interactifs d'informatique

Collection d'interfaces web interactives pour visualiser et s'entraîner sur les algorithmes et structures de données au programme d'informatique (ITC) en classes préparatoires (CPGE, deuxième année).

Aucune installation : chaque outil s'ouvre directement dans le navigateur.

## Utilisation en local

```bash
git clone https://github.com/siicpgeamansur/ITC.git
cd ITC
```

Ouvrez ensuite le fichier `.html` de votre choix dans un navigateur récent (Chrome, Firefox, Edge, Safari).
