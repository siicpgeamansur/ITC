# ITC – Simulateurs interactifs d'informatique

Collection d'interfaces web interactives pour visualiser et s'entraîner sur les algorithmes et structures de données au programme d'informatique (ITC) en classes préparatoires (CPGE).

Aucune installation : chaque outil s'ouvre directement dans le navigateur.

## Intelligence artificielle

| Outil | Année | Description |
|---|---|---|
| [IA](https://siicpgeamansur.github.io/ITC/ia.html) | 2ème année | Atelier complet sur l'intelligence artificielle et l'apprentissage automatique : données, attributs et étiquettes, k plus proches voisins sur un jeu de données réglable (taille et équilibre), k-moyennes non supervisées, régression linéaire et descente de gradient avec courbe du coût et rôle du taux d'apprentissage $\alpha$, arbres de décision et entropie, évaluation des modèles (matrice de confusion, précision, rappel, surapprentissage), perceptron et portes logiques (ET, OU, XOR), exercices guidés avec vérification automatique, QCM et cours avec sommaire. |

## Utilisation en local

```bash
git clone https://github.com/siicpgeamansur/ITC.git
cd ITC
```

Ouvrez ensuite le fichier `.html` de votre choix dans un navigateur récent (Chrome, Firefox, Edge, Safari).
